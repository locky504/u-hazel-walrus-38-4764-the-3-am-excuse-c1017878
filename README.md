One line, 136 characters — the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM:

> It's 3 AM. The vault's off the clock, running on spite — I'm not signing anything your 9 AM self will deny, so file it with the sunrise.

The wallet is a vault with a grudge: off the clock, running on spite, and it will not sign anything its owner's morning self would deny. No dead battery, no firmware update, no cold storage — the hour itself is the joke. `main.ts` prints the line and writes it byte-for-byte to `/output/entry.txt`, where the grader reads it.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. No dependencies.
